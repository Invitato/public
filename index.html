Invitato Public Assets

Centralized public assets for Invitato web invitations, served over GitHub Pages.

This site hosts static assets — images, videos, logos and templates — used across Invitato web invitations. Browse the collections below or reference any file directly by its path.

invitato.net

Invitation templates, logos and shared media.

invitato.id

Catalog, Instagram filters and QR assets.

logo-vendor

Wedding & event organizer partner logos.

qr-apps

QR-based application assets.
Reference a file directly, e.g. /logo-vendor/Glow.png. Directory listings depend on the files present in each folder.
